关于 M2.9

M2.9 · Material Components for Web

版本: v2.9.0 (Extended from Google MDC-Web v0.34.1)

融合 Material Design 3 (Material You) 动态调色哲学与 经典 Material Design 极简直角几何美学的下一代 Web 响应式组件库与全景交互展厅系统。

stars 核心架构特性
• 0px 极简直角几何：消除冗余圆角，呈现硬朗高密度的专业质感。
• Monet 动态调色盘：CAM16 / HCT 色彩空间，支持 1/2/3 色自由维度。
• AOSP 原生 EdgeEffect：1:1 复刻 Android 5-11 边界弧形反比自适应水波纹。
• 响应式双轨导航：桌面端 Hover 展开轨 + 移动端 0.39s 靠底独立抽屉。
• 纯直角扩展套件：日历/时钟选择器、分段按钮、手风琴折叠卡片、浮动滚动条等。
