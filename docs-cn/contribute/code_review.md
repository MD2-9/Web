# 代码评审规范 (Code Review)

所有合并至 `main` 分支的代码拉取请求 (Pull Request) 均需通过严格的代码审查。

---

## 1. 评审核查清单

### 1.1 架构与设计
- [ ] 动态组件是否严格践行 Foundation / Adapter 解耦设计？
- [ ] Foundation 中是否杜绝了对宿主 DOM（如 `document`、`window`）的直接访问？
- [ ] 是否在 `destroy()` 中完整清理了所有事件监听器与定时器？

### 1.2 样式与几何
- [ ] 是否遵循 M2.9 的 0px 纯直角与 50% 纯圆几何规范？
- [ ] 是否使用 `var(--mdc-theme-*)` 变量支持莫奈动态色彩？
- [ ] 类名是否符合 BEM 命名规范？

### 1.3 响应式与体验
- [ ] 桌面端（$\ge 600\text{px}$）与移动端（$< 600\text{px}$）是否均能正常自适应？
- [ ] 移动端是否符合单手操作习惯（如向下对齐）？
