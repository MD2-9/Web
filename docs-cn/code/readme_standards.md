# README 编写标准 (README Standards)

每个位于 `packages/mdc-*` 下的独立包都必须包含一份完备的 `README.md` 文档。

---

## 1. 必备小节结构

1. **标题与包说明 (Title & Summary)**：组件名称与核心功能概括。
2. **安装与引入 (Installation & Usage)**：NPM 安装命令、SCSS 引入方式与 JavaScript 模块导入。
3. **HTML 结构与代码范例 (HTML Structure)**：最小化可用模板与主要修饰符变体。
4. **JavaScript API 参考 (JS API Reference)**：类名、构造函数参数、公共方法与属性列表。
5. **Adapter 与 Foundation 接口 (Adapter & Foundation)**：Adapter 抽象方法签名与职责说明。
6. **CSS 类名与变量表 (CSS Classes & Variables)**：导出的所有 Block、Element、Modifier 类名与支持的 CSS 自定义属性。
