# 页面布局系统与右侧常驻组件栏指南 (Layout & Component Panel)

> **核心设计理念**：遵循 **0px 纯直角与 50% 纯圆几何规范**，通过桌面端多面板避让、流式容器查询、自研零宽度悬浮滚动条与纯直角悬浮 Tooltip 引擎，打造高效率、可定制、零抖动的现代工作台布局。

---

## 1. 架构总览 (Architecture Overview)

├──────────────┬──────────────────────────────────────────┬──────────────────────────────┤
│ 1. 导航导轨  │ 2. 主内容区 (main-container)             │ 3. 右侧常驻组件栏 (290px+)   │
│              │                                          │                              │

## 2. 右侧组件栏 (`MdcComponentPanel`)

### 2.1 响应式展示规范

| 视口尺寸 | 显示形态 | 布局与交互行为 |
| :--- | :--- | :--- |
| **桌面端 (≥768px)** | **固定常驻** | 紧贴视口右侧，主内容区 `main-container` 自动让出 `var(--component-panel-width)` 空间。 |
| **移动端 (<768px)** | **抽屉滑入** | 默认移至视口右侧之外（`translateX(100%)`）。可通过**屏幕右边缘向左滑动**或点击左侧导航「组件」入口唤出。 |

### 2.2 自由拖拽调整宽度 (Resizable Handle)
- **左边缘手柄**：组件栏左侧配置 8px 交互手柄，鼠标悬停时呈现 2px 扁平直角主题色线条，无杂乱发光光晕。
- **拖拽范围约束**：支持在 **220px 至 840px**（或视口上限）之间自由无级缩放。
- **流畅跟手**：拖拽期间自动为 `<body>` 注入 `.is-resizing-component-panel`，禁用过渡动画与文本选中，提供绝对跟手的操作体验。
- **记忆与重置**：
  - 调整后的宽度自动持久化写入 `localStorage.setItem('m29_component_panel_width', width)`。
  - **双击手柄**：一键还原为标准默认宽度 **290px**。

### 2.3 容器自适应双列排版与子组件 1:1 坐标锁死
- **Container Query 双列流式**：组件栏内部容器（`.component-panel-body`）配置了 CSS Container Query。当组件栏向左拖宽至 $\ge 520\text{px}$ 时，内部自动从单列垂直排列无缝切换为 `repeat(2, minmax(0, 1fr))` 左右双列排版。
- **高亮圆点 100% 坐标锁死**：
  - 在鼠标拖拽调整组件栏宽度、双击重置或窗口缩放过程中，DatePicker 日历选中高亮指示器（`selection-thumb`）通过 `ResizeObserver` 与动态计算实现**零延迟绝对锁死**在目标日期/月份单元格中心，彻底杜绝漂移与错位。

## 3. 文章卡片单/双/三栏排版系统 (Card Columns Layout · FLIP 动效 ✖ 莫奈三色列着色)

主内容区域彻底移除了生硬的 `1200px` 固定上限，全面采用 **自适应横向瀑布流 + FLIP 平滑过渡动画引擎**：
- **顺序严格从左往右**：卡片按 $1 \to 2 \to 3 \to 4 \dots$ 自然横向阅读顺序分配至各列；
- **FLIP 布局平移动画**：当切换列数或发生响应式降级时，卡片伴随 **0.42s 流体阻尼平移动画**（`cubic-bezier(0.16, 0.9, 0.22, 1)`），丝滑飞入新列，告别生硬跳跃；
- **莫奈三色列着色系统 (Column-based Color Tones)**：
  - **第 1 列（左列）**：全列卡片统一使用 **Primary 主色**（`--mdc-theme-primary`）；
  - **第 2 列（中/右列）**：全列卡片统一使用 **Secondary 次色**（`--mdc-theme-secondary`）；
  - **第 3 列（右列）与组件栏（Component Panel）**：统一使用 **Tertiary 第三色**（`--mdc-theme-tertiary`）！
- **间距规范**：左右保持标准列间距（双栏 24px / 三栏 20px），垂直方向统一为 **1.2 倍垂直间距**（`calc(16px * 1.2) = 19.2px`）。

### 3.1 三种排版形态

| 排版模式 | 宽度与间隙特征 | 莫奈三色列色彩布局与视觉表现 |
| :--- | :--- | :--- |
| **单栏模式 (1 Column)** | 限制 `960px` · 1.2倍垂直间隙 | **水平绝对居中**，全列卡片使用 Primary 主色，右侧组件栏使用 Tertiary 第三色。 |
| **双栏模式 (2 Columns)** | 100% 满宽 · 瀑布流 (左右24px / 上下1.2倍) | **第1列主色，第2列次色，右侧组件栏第三色**，高度不一致时自动向上紧凑补齐。 |
| **三栏模式 (3 Columns)** | 100% 满宽 · 瀑布流 (左右20px / 上下1.2倍) | **第1列主色，第2列次色，第3列与组件栏第三色**，全景三色列层次分明。 |

### 3.2 净可用宽度实时计算与阶梯自动降级保护 (核心算法)

降级判断严格基于**主内容区域的净可用宽度**进行动态计算：

$$\text{AvailableWidth} = \text{WindowWidth} - \text{RailWidth (72px)} - \text{PanelWidth (当前组件栏实际宽度，收纳时为 0)}$$

- **计算联动场景**：无论是**缩放浏览器窗口**、**开启/折叠关闭组件栏**，还是**鼠标拖拽拉宽/拉窄组件栏手柄**，系统均以 60fps 实时重算 $\text{AvailableWidth}$：
  - **三栏模式阶梯降级**：
    - $\text{AvailableWidth} \ge 860\text{px}$：完整呈现 **3 栏**全景（各列占 1/3，左右间距 20px）。
    - $560\text{px} \le \text{AvailableWidth} < 860\text{px}$：**平滑降级为 2 栏**（`downgrade-2col`），样式与间距**完全与标准 2 栏一致**（各列满宽平分 50%，左右间距 24px，右侧绝不留空）。
    - $\text{AvailableWidth} < 560\text{px}$：**再降级为 1 栏**（`downgrade-1col`，限制 960px 居中）。
  - **双栏模式阶梯降级**：
    - $\text{AvailableWidth} \ge 560\text{px}$：正常呈现 **2 栏**（各列 50%，左右间距 24px）。
    - $\text{AvailableWidth} < 560\text{px}$：**自动降级为 1 栏**（`downgrade-1col`）。

## 4. 二级菜单水波纹动画速率 (Secondary Panel Ripple Speed)
- **常规二级菜单（目录、设置、关于）**：打开时的水波纹圆形扩散速率放缓为原来的 **29%**（动画时长由 0.35s 调整为 **1.2s**），呈现极其细腻、从容的莫奈水波纹扩散效果。
- **调色盘面板 (`#themePickerPanel`)**：维持原本高效的 **0.35s** 响应速度不变。

## 4. 零宽度浮动悬浮滚动条 (`M29OverlayScrollbar`)

解决经典滚动条占据 15px~17px 宽度所引起的**容器内容被挤压**与**滚动条出现/消失时的布局跳动 (Layout Shift)** 问题：

1. **彻底屏蔽原生粗滚动条**：全局启用 `scrollbar-width: none` 及 `::-webkit-scrollbar { display: none; }`。
2. **全站零像素占用**：自研悬浮滚动指示器完全通过绝对/固定定位悬浮于内容之上。
3. **平滑淡入淡出**：仅在滚动时呈现莫奈主题色滑块，停止滚动约 1 秒后自动渐隐。
4. **手势与拖拽支持**：支持鼠标直接按住滑块拖拽滚动，或点击轨道快速跳转定位。
5. **智能避让**：整页滚动条在桌面端自动对齐至组件栏左侧边界，移动端对齐至屏幕边缘。

## 5. 纯直角 Material 悬浮 Tooltip 引擎 (`M29TooltipEngine`)

- **0px 纯直角几何**：严守 M2.9 纯直角设计语言，彻底抛弃圆角与浏览器原生黄色系统提示框。
- **全局拦截与转接**：智能捕获所有带 `title` 或 `data-tooltip` 的按钮、图标与导航项，自动转接至 `M29TooltipEngine` 浮层。
- **智能方位计算**：默认向上弹出，空间不足时自适应翻转至下方或侧方，并具备防快速滑过抖动延时（80ms）。
- **莫奈反色表面**：浅色模式下使用深灰反色表面（`#322f35`），暗色模式下使用高明度反色表面（`#e6e1e5`）。

## 6. 侧边栏底部控制面板 (Sidebar Footer Controls)

遵循**外部极致收敛、内部功能完备**的设计准则：

- **72px 紧凑收起态（外部）**：仅居中展示单个**暗色模式切换按钮**（`brightness_4` / `brightness_7`），与上方的纵向动态标题保持宽敞间距，绝无重叠挤压。
- **260px 悬浮展开态（内部）**：横向并排呈现 **4 个纯图标操作按钮**（无文本描述，悬浮展示 M2.9 直角 Tooltip）：
  1. 🧩 **组件栏**（`widgets`）：
     - **电脑端 (≥768px)**：点击作为**开关**（展开/收起折叠右侧常驻组件栏，主内容区自适应让出/占满空间）。
     - **手机端 (<768px)**：点击作为**调出**（唤出右侧组件栏抽屉面板）。
  2. 🌐 **语言切换**（`translate`）：中英文（`zh-CN` / `en-US`）即时切换。
  3. 📐 **布局切换**（`view_column` / `view_agenda`）：单栏 / 双栏排版切换。
  4. 🌙 **暗色模式**（`brightness_4` / `brightness_7`）：慢速水波纹日夜间切换。
