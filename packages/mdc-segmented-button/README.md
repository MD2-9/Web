# M2.9 Segmented Button (@material/segmented-button)

0px straight-angle segmented button group conforming to M2.9 geometry specifications.

## Installation

```bash
npm install @material/segmented-button
```

## Usage

### HTML
```html
<div class="m29-segmented-button-group">
  <button class="m29-segmented-button is-selected">View 1</button>
  <button class="m29-segmented-button">View 2</button>
  <button class="m29-segmented-button">View 3</button>
</div>
```

### SCSS
```scss
@import "@material/segmented-button/mdc-segmented-button";
```
